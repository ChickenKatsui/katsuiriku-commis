Setup

Supabase belum dikonfigurasi

Panel admin dan data live memakai Supabase. Situs publik tetap jalan dengan data cadangan selama setup belum selesai.

  1. Buat project gratis di Supabase.
  2. Jalankan SQL setup dari panduan di repo (tabel, RLS, realtime). Jika database sudah ada, jalankan juga migrasi status layanan, harga, serta jadwal & About Me.
  3. Buat user admin di Authentication → Users, lalu masukkan UUID-nya ke tabel admin_users.
  4. Salin Project URL dan anon public key ke assets/js/supabase-config.js.
  5. Refresh halaman ini, lalu login.
